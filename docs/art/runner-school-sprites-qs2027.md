# QS 2027 高校奶狗 2D 图集

皮肤商城覆盖 QS 2027 世界大学排名第 1 至并列第 100 名，共 102 所学校。学校名单与徽标来源见 [`src/runner/qs2027-top-ranked.json`](../../src/runner/qs2027-top-ranked.json)。

每所学校对应一张独立的透明 WebP 图集，路径为 `public/assets/runner/qs2027/skins/qsNNN.webp`，统一 4 列 × 2 行。第一排是四足奔跑的着地、伸展、腾空和收腿。第二排是待机、起跳、二段跳和低身下滑。摔落使用该校的空中姿势配合下坠动画。角色图集以 2D 精灵的方式显示在跑道上，校徽元素绘制在各校服装上。

## 生图方式

- 工具：Codex 内置 `image_gen.imagegen`，逐校单独生成。
- 参考：用户提供的原始奶狗形象；对应学校在 QS 页面展示的徽标。
- 共同提示词要点：全新奶狗角色、圆润略长身体、真实四足运动、背向镜头的后三分之四视角、完整的 4×2 动作布局、八帧造型一致、透明背景、无文字和场景。
- 逐校差异：学校名称与徽标、主色和辅助色、犬种特征与毛色、耳朵和尾巴形态、制服的剪裁与徽纹位置。徽纹是服装设计的一部分。
- 输出后仅做技术处理：缩至 1024×512，清理生成图透明区域中的低 alpha 噪点，并压缩为 WebP。源 PNG 保留在 Codex 生成图目录，项目只引用 WebP。

这套图集的徽纹由生成模型依据学校徽标绘制，细节可能与官方矢量校徽略有差异；商城列表同时展示学校在 QS 页面的原始徽标，方便识别。
