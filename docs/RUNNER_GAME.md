# 奶蛙逃亡

0.32.0 候选，尚未发布。玩家是用户提供的**奶狗**：黄色、棕耳、短腿、稍长而圆的身体；**恐怖奶蛙是追赶者**。主菜单分别展示两者。奶狗采用八帧四足奔跑，跳跃、落地、下滑和转弯有独立动作。[奶狗与道具原图、完整提示词](art/runner-milk-dog-v2.md)。

实际背景、动态地面和障碍继续使用写实峡谷水渠、湿石板和透明图集。[场景美术记录](art/runner-aqueduct-v1.md)。参考[Imangi的跑酷说明](https://imangistudios.com/thegames/temple-run/)，玩家文案简化为“开始游戏、无限模式、暂停、继续、游戏结束、再跑一次”等短语。

## 模式与操作

- **无限模式**默认选中，直接开局，没有距离终点，跑过1000米不会打断。
- **千米挑战**跑到1000米结算，奶狗与原普通奶蛙捧腹大笑同屏庆祝。可选“继续无限模式”，保留当前距离和金币继续跑。
- 三条轨道自动前进，基础速度从12米/秒逐渐增加到28米/秒。
- ← / → 或 A / D 换道；↑ / W / 空格跳跃；↓ / S 下滑；Esc / P 暂停。手机滑动或点底部按钮，详细说明收在“玩法说明”。
- 木箱换道或跳过；横梁换道或下滑；断桥换道或跳过。每180米出现弯道，提前65米提示，最后16米按方向转弯。错过或转错方向结束本局。

## 道具、金币与追赶

- **磁铁**持续10秒，自动收集前方12米内三条轨道的金币，跳跃和下滑时也能吸取。
- **护盾**保留20秒，抵挡一次障碍撞击或断桥掉落，随后消耗。
- **冲刺**持续5秒，速度为基础的1.5倍，自动越过障碍和转弯，并甩开追赶者。
- 金币基础50分，每连续收集10枚提高1倍金币分数，最高5倍；4秒未收币或撞击后连击重置。距离每米10分。
- 第一次无保护撞木箱或横梁会减速1秒，恐怖奶蛙从身后逼近；8秒内再撞会被抓，安全跑8秒可拉开距离。断桥和转弯失误直接结束。
- 撞击或护盾抵挡后有1.25秒碰撞保护，防止同一个障碍连续判定。
- 每四组障碍在安全轨道依次生成护盾、磁铁、冲刺。每组保留至少两条安全轨道，弯道前后30米不放障碍；千米挑战的目标前后30米留空。

## 纪录、暂停与资源

千米挑战使用原键 `nwaxz-runner-record-v1`，无限模式使用独立键 `nwaxz-runner-endless-record-v1`，分别记录最高分、最远距离、单局最多金币。保留已有跑酷纪录，不迁移其他模式存档。没有云端同步、匹配或排行榜。存储失败会提示。

暂停、后台和失焦不推进距离、步态、追赶、连击或道具计时，返回后手动继续。模拟固定120Hz，长帧最多推进0.1秒。简化动作关闭奔跑循环和镜头晃动，保留可辨认的跳跃、下滑及原奶蛙大笑。音乐与音效沿用全局设置。

进入模式后按需加载角色、场景和道具；六张PNG保留原尺寸和字节，共约12.70MiB，尺寸/哈希见 `public/assets/runner/manifest.json`。完整离线包覆盖新增资产，首次在线使用也由PWA缓存；未缓存的资源需要联网。载入可返回、失败可重试，取消后旧任务不覆盖首页。

## 验证

`server/runner.test.mjs` 纳入 `pnpm check`，覆盖碰撞、追赶、道具、连击、暂停、八帧犬类步态、模式、纪录与原图字节；40个种子连续模拟至少3000米，检查路线可通行和对象数量有界。

浏览器脚本 `ops/runner-browser.mjs` 先启动 `pnpm dev`，使用独立Playwright或 `PLAYWRIGHT_MODULE`，可选 `CHROMIUM_PATH`。覆盖真实入口、独立QA实例的千米/无限、键盘、触摸、玩家/追赶者资源区分、道具效果、暂停和保存。生产代码没有调试入口。千米结果以确定性模拟推进，不宣称真人连续通关。真实手机帧率、手指触感和扬声器听感仍待真机验收。
