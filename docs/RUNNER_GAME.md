# 奶狗快跑

本文记录 PR 候选版本的跑酷玩法。原名“奶蛙逃亡”，因主角是奶狗而改名。玩家是**奶狗**（黄色、棕耳、短腿、圆身），**恐怖奶蛙是追赶者**。奶狗采用八帧四足奔跑，跳跃、下落、下滑有独立动作。[奶狗与道具原图、完整提示词](art/runner-milk-dog-v2.md)。

角色是原 2D 原画，以只绕竖轴转向镜头的平面立在 Babylon.js 3D 场景里；道路、障碍、转弯、天气是真 3D。奶狗图集里肉眼几乎看不见的彩色噪点（alpha < 40）在载入时清除，磁盘上的原图字节不变。

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/runner/world.ts` | 纯模拟（120Hz 固定步长）：移动、跳跃物理、碰撞、道具、追赶、路线生成 |
| `src/runner/renderer3d.ts` | 3D 场景：道路槽位与三套主题、障碍模板、转角、天空环带、镜头、天气、道具特效、抓捕演出 |
| `src/runner/game.ts` | 界面与输入：HUD、单条操作提示、菜单/暂停/结算、键盘/滑动/按钮/倾斜、纪录 |
| `src/runner/shop.ts` / `qs2027-top-ranked.json` | 皮肤商城、QS 2027 高校数据、货币余额与本地存档读取 |
| `src/runner/course.ts` / `route3d.ts` | 场景路线（固定行程）、路面高程、地形路段、独木桥弯道位置、世界坐标与圆角转弯 |
| `src/runner/actors2d.ts` / `animation.ts` | 2D 角色平面与帧选择 |
| `src/runner/ambience3d.ts` | 场景生灵：飞鸟、海鸥、秃鹫、蝙蝠、蝴蝶、落叶、萤火虫、矿洞浮尘、风滚草（两组精灵） |
| `src/runner/missions.ts` | 任务：任务列表、单局进度、发放顺序、奖励与本地存档读取 |
| `src/runner/progression.ts` | 局外成长：道具升级（等级、时长、价格、购买）与每日奖励（连续天数） |

## 渲染与性能

- 场景放在固定世界坐标里，路面按4米一块放在44个循环槽位中，只在槽位回收时重新摆放一次；每帧只移动镜头、奶狗和特效。装饰（桥墩、石柱门、树、路灯、矿洞支架）按绝对路块编号出现，不会随画面跳动。
- 只有半球光和方向光两盏灯，材质最多计算2盏灯；夜间路灯用自发光灯泡和光晕表现，不用点光源。
- 载入时预热渲染一帧，提前编译障碍、道具和特效的着色器。
- 天空是跟随镜头位置、不随镜头旋转的圆柱环带，取每张场景图左侧的山崖/树林/天空条带镜像拼成无缝全景，转弯时背景与道路方向一致。
- 大地面每 70 米重新对齐一次位置，水面、草地、洞底贴图都按 70 米整数次重复，避免对齐时贴图跳动。水渠水面使用水波贴图并缓慢流动。道路和墙面贴图开启 8 倍各向异性过滤（高画质 16 倍），远处路面更清晰。
- 奶狗起跳时略微拉长、落地时略微压扁，换道时身体向移动方向轻微倾斜；撞击时镜头沿画面左右方向抖动并逐渐停下。减少动态效果设置会关闭这些效果。
- 竹林、峡谷、雪原三个场景没有原画，天空带在载入时用代码绘制（渐变、层叠山脊、雪顶、薄雾，夜里加星星），左右首尾相接。雪地用代码生成的雪面纹理，避免石材纹理在强光下发灰。
- 精细道具（路灯、竹丛、雪松、仙人掌、矿洞岩壁、蘑菇和青藤倒木等）在建模板时按材质合并成少数几个网格，再按槽位实例化；路灯光晕等公告板不合并。竹丛、雪松、岩柱等每个槽位随机转向和缩放，避免同一模型排成一列。
- 独木桥一带的地面按桥的每一段挖开，下面是一整片海面；海上不种树。
- 游戏循环先预约下一帧再计算和绘制，并接住单帧里的错误（控制台只报一次）：以前任何一帧出错都会让循环停下，画面卡住、按钮也没反应。
- 开新一局时，滑索和独木桥按新路线重建（以前记录的路线版本号不会清零，新路线的版本号碰巧相同时会沿用旧的桥和滑索位置）。
- 开新一局时，所有路块槽位都会重新摆放。以前重置用的标记 -1 恰好也是起点后方那块路的编号，那个槽位会被跳过，还留着上一局的坑洞；如果上一局正好死在那里的坑、桥或滑索上，新一局一开始就会渲染出错、画面卡住。
- 帧率：每个路块只搭当前场景的路面和布景，进入别的场景时再换；以前每块路都备好六个场景的全套，场景里常驻八千多个网格。路块摆好后冻结世界矩阵，只在重新摆放或开出坑洞时解冻。模板源网格在预热后整体停用（实例照常绘制）。金币和路面零件合并成一个网格。桌面浏览器上每帧 CPU 时间中位数从约 9 毫秒降到约 2.5 毫秒，网格从 8563 个降到约 2700 个。
- 自动分辨率：跑动中如果持续掉到每秒 47 帧以下，渲染分辨率每次降 12%（最低 55%）；连续 8 秒高于 57 帧再逐步升回。
- “高清”画质下，路面、石块、岩壁、台地和土坡加一层代码生成的细小凹凸（可平铺的三层噪声法线贴图），受光时有颗粒质感；“平衡”画质不加，不增加手机负担。
- 右上角的本局货币用银币、金币（有钻石时再加钻石）图标加数字显示，收到货币时轻轻一弹。
- 道具计时是图标外的一圈彩色圆环，随剩余时间减少，最后 2 秒闪烁；道具开始时从右侧弹入，其他计时不会跟着重画。连击倍数每次升级时放大弹一下。
- 障碍物（倒木、栏杆、巨石、乱石、滚石、矿车、木箱、落石）和道具、宝箱、闹钟、灯笼下面有一块柔和的接地阴影，大小按模型占地自动计算；道具只是模型上下浮动，地上的光圈和阴影不动；奶蛙扔来的木箱落地后才有阴影。拿到道具或打开宝箱时，从奶狗脚下扩散一圈道具颜色（宝箱为金色）的光环。
- 音效（代码合成，跟随“音效”开关）：起跳、二段跳（更亮）、下滑和空中急降各有风声，落地一声闷响，换道和转弯轻轻一扫；连续收币时音高沿五声音阶逐级升高；惊险闪避一声呼啸，撞到路边或踉跄一声闷撞，被抓时一声重撞（同时画面中心白光、四周泛红地闪一下），落水有水花声；道具、闹钟和灯笼是上行琶音，宝箱是一串清亮的音符。挂在滑索上时滑轮一直呼呼作响（越快音越高，松手前停下），气球飞行时有轻轻的风声。踉跄后奶蛙追在身后时响起心跳声（约 0.7 秒一下）；暗夜逃亡里奶蛙逼近到 9 米以内也有心跳，越近越快（最快约 0.4 秒一下）。
- 画面外推：模拟按每秒 120 步固定推进，屏幕刷新却不一定整齐（60 Hz 屏幕偶尔一帧 1 步、下一帧 3 步，144 Hz 屏幕更乱），以前奶狗和镜头会随之一顿一顿。现在绘制时用上一步之后还没模拟的时间把路程和换道位置往前补齐（最多一步，约 0.25 米），无论屏幕刷新率多少都匀速移动；碰撞和得分仍按固定步长判定。奶狗奔跑时随步伐上下起伏。
- 场景生灵全部是一张代码绘制图集里的精灵（萤火虫和浮尘另用一张发光精灵），合计两次绘制调用，每帧只更新几十个精灵的位置；减少动态效果时数量减半。脚下扬尘、滚石尘土、矿车火花、惊险闪避的白色划痕都是小型粒子系统。画面四角的暗角由页面 CSS 叠加，不进 3D 着色器。
- 帧耗时（桌面 Chromium，连续绘制 60 帧取中位数，五个场景各测 5 轮）：改动前平均 3.6 毫秒，加入这一轮内容后 3.8 毫秒；其中场景生灵约 0.2 毫秒。曾试过在材质着色器里加对比度和暗角，竹林这类叶片层层叠叠的场景每帧多 1 毫秒以上，已改为 CSS 暗角。加入奶蛙动作、围观奶蛙、接地阴影和拾取光环后，同样方法（六个场景各 4 轮）测得平均 2.3 毫秒（水渠 2.5、遗迹 1.5、矿洞 3.1、竹林 2.9、雪原 2.3、峡谷 1.7）；这次没有和旧版本在同一时间同场对比，机器负载不同，数字只说明没有明显变慢。道具实例的创建和销毁每个约 0.03 毫秒，不是卡顿来源，因此没有做对象池。

## 模式与操作

- 开始界面有五张模式卡片：**无限奔跑**（经典）、**每日挑战**、**金币冲刺**、**暗夜逃亡**、**夺回金苹果**。每个模式各有自己的最高分。
- **无限奔跑**默认选中，一直跑到被抓或摔落。开局不选场景，所有场景合成一条固定路线，按路程自动切换。
- **每日挑战**：规则同无限奔跑，路线由当天日期生成（本地日期，零点换新），同一天所有人跑同一条路线；纪录只记当天，开始界面显示“几月几日 · 今日最高分”。
- **金币冲刺**：60 秒倒计时，开局速度约 15 米/秒；每组障碍后多一串更密的金币，金币比例 15%（无限模式 1500 米后才有金币）；每五组障碍放一个闹钟，捡到加 5 秒。时间到即结束，奶狗和普通奶蛙捧腹大笑庆祝，结算显示一分钟收了多少银币、金币和闹钟；撞上致命障碍会提前结束。全程白天，不能续命。脚本玩家平均每局约 85 秒。
- **暗夜逃亡**：全程黑夜，雾气把视野压到约 50 米，看不到远处的天际线，奶狗提着一盏灯笼照亮身边；恐怖奶蛙一直跟在身后 16 米，每秒逼近 0.3 米（越往后越快，2000 米时翻倍），撞到可恢复的障碍会被它拉近 6 米，距离归零就被抓（“在黑暗里被恐怖奶蛙抓住了”）。每三组障碍放一盏灯笼，捡到把奶蛙逼退 5 米（最远 26 米）并加 100 分。没有转弯提示。上方显示“奶蛙在身后 N 米”和一条距离轨道，奶蛙靠近到镜头前才看得见。脚本玩家平均跑约 3.2 公里（1.4–5 公里）。
- **夺回金苹果**（特别模式，取代原来的千米挑战）：恐怖奶蛙抢走了附魔金苹果在前面逃，奶狗要在 80 秒内追上它。全程白天，从雪原起跑，经过雪原和赤岩峡谷的两段下坡滑索，没有长落穴。开局相距 30 米；奶蛙比奶狗的正常速度慢 1%，每收一枚币再拉近 0.1 米，每秒最多拉近 2.2 米（冲刺、滑索也不能一下追上），相距 5 米以内奶狗会扑上去。撞到可恢复的障碍或撞到路边不会被抓，但奶蛙会拉开 10 米（撞墙 6 米）。奶蛙在跑道间来回换道，每隔几秒往身后扔一个木箱，落在它所在的道上，要换道或跳过；扔之前会避开弯道、滑索和其他障碍。追上（相距 1.4 米）即胜利：奶狗与原普通奶蛙捧腹大笑同屏庆祝，得分加 2000 分和每剩一秒 300 分；时间到就算奶蛙跑掉，它在前面转身捧腹大笑。致命障碍仍会结束这一局。脚本玩家无失误时约 40–58 秒追上。
- 开始界面是游戏大厅：三维场景铺满画面，镜头低角度从正前方偏右看着奶狗（默认奶狗用正面笑脸造型，缓缓呼吸、隔几秒蹦一下；学校皮肤只有背面图，镜头改在身后斜侧），恐怖奶蛙在身后远处手搭凉棚张望，隔几秒捧腹大笑。左上是标题和本模式纪录，右上是银币、金币、钻石，下面是可展开的任务（大屏默认展开），奶狗脚下是皮肤名称，拥有两款以上时两侧有箭头直接切换；底部是模式卡片、模式说明、会轻轻跳动的“开始奔跑”大按钮和商城、升级、说明、倾斜控制、返回。
- 点开始后镜头在约 1.15 秒内从正面绕到奶狗身后（平滑起落，没有跳变），奶狗先笑着小跑起步，镜头转过侧面后换成背面奔跑；奶蛙在镜头转身时留在另一侧，再慢慢追近。减少动态效果时直接从身后开始。
- 开跑时屏幕中间弹出“出发！”（金币冲刺为“60 秒收金币”，暗夜逃亡为“奶蛙就在身后”；夺回金苹果仍是原来的提示）。二段跳时奶狗在空中翻滚一圈（在最右道时反方向翻），减少动态效果时不翻。
- 暂停界面显示本局路程、得分、银币、金币·钻石，以及三个任务在这一局里的进度。
- 加载跑道时显示一条随机的小贴士（操作、岔路、惊险闪避、连击、道具升级、灯笼等）。
- 结束界面：上方是结局（失败时旁边是捧腹大笑的恐怖奶蛙）、死在哪个场景第几米，以及一条提示；中间是大号得分和“新纪录”标记，下面是路程、用时、银币、金币和钻石；无限模式显示离最远纪录还差多少米，特别模式显示离奶蛙还差多少米；回车可再来一局。结算卡片弹入，得分在约 1.1 秒内从 0 滚到最终分数，四项统计依次弹出，“新纪录”像印章一样盖下来（减少动态效果时直接显示）。
- 场景名（如“雪原 · 雪”）只在开局和每次进入新场景时出现约 3 秒，随后淡出。
- 速度从13米/秒随距离升到30米/秒。开局约90米只有银币，前两组障碍是单道栏杆，之后逐渐加难。
- 电脑：← → / A D 换道或转弯，↑ / W / 空格跳，↓ / S 下滑，Esc / P 暂停，回车开始/再来。手机：画面上滑动（手指移动约26像素即触发，不必松手），或底部按钮（仅触屏显示）；可开启倾斜换道。
- 跳跃为真实抛物线，空中可二段跳；落地前按跳会缓冲到落地瞬间；空中按下滑会急降并接下滑。

| 栏杆 | 单道 | 换道或下滑 | 同上 |

| 乱石枯枝 | 碎石和枯枝 | 雕花碎石块、柱段、树根 | 矿石、水晶碎片、断枕木 | 一排削尖的竹签 | 冰锥 | 仙人掌丛和砂岩 |
| 倒木 | 原木（约一半长蘑菇） | 缠青藤的原木（约一半长蘑菇） | 铁箍方木垛 | 捆好的竹捆 | 盖着雪、挂冰柱的原木 | 晒白的枯树干 |

裂缝和长落穴的坑沿都有崩落的碎块，遗迹和竹林还垂着树根，矿洞挂着断枕木，雪原挂着冰柱，峡谷是翘起的干裂土块。巨石、碎石统一改用随机起伏的多面石块，不再是规则多面体。活动木板上的铁条、苔藓、积雪等随木板一起翻落。

已经在最左（或最右）道还往外换道，奶狗会撞到路边：身体向路边一顿再弹回，镜头抖动、扬起尘土、手机震动，并引来奶蛙，和撞到栏杆一样；被追时再撞会被抓（“撞墙后被恐怖奶蛙抓住了”）。护盾、无敌、矿车、滑索和独木桥上不算撞墙，撞后 1 秒内连按也只算一次。

踉跄后 8 秒内再撞会被抓。护盾可抵挡一次障碍物碰撞。整条路的障碍会显示操作提示，长落穴会分两次提示起跳和空中再跳。每次长落穴之后留有额外的落地空间。

**滚石与失控矿车**：跑过 350 米后，遗迹长廊的刻纹石球、赤岩峡谷的红砂岩滚石、雪原的大雪球会沿一条道朝奶狗滚来，矿洞里则有装满矿石、亮着车灯冲过来的失控矿车（这四个场景里，前后路况允许时约四分之一的障碍行换成它们）。它们先停在路上，奶狗靠近时才出发：滚石每秒 8 米、矿车每秒 10 米，出发时机让它们恰好滚 12 米与奶狗相遇，所以相遇位置和一块静止障碍差不多；生成时整段助跑都避开弯道、滑索、独木桥和矿车道，并给下一组障碍多留 4 米。滚石边滚边转，身后扬起当地颜色的尘土或雪粉；矿车车身摇晃，车轮冒火花，车灯在前方照出一道光锥；靠近时镜头轻微震动，出发时有一声低沉的轰隆。它沿着奶狗所在的道滚来时，屏幕提示“石球滚来了 / 滚石来了 / 大雪球滚来了 / 矿车冲过来了 · 换道或二段跳”。撞上会结束这一局（滚石要二段跳才越得过，矿车高 1.45 米同样要二段跳）；躲开后它会继续往奶狗身后滚走。特别模式“夺回金苹果”里不出现，那里已有奶蛙扔来的木箱。

**惊险闪避**：撞上前 0.3 秒，如果奶狗原样不动就会撞上，之后却及时换道、起跳或下滑躲开，就算一次惊险闪避：加 100 分（乘当前连击倍率，双倍得分或附魔金苹果时再翻倍），连击计数加 2 并续上 4 秒。画面中部弹出“惊险！+分数”，连续几次时显示“惊险 ×N”，奶狗身边掠过几道白色划痕。提前躲开、被撞到、无敌时都不算；长落穴本来就要贴着坑沿起跳，不计入。

普通路段的直角弯按约 260–380 米的间隔生成，遇到滑索、独木桥或矿车时会调整位置。弯道在离拐角点 11 米处离开直道，沿 18.2 米长的曲线转过 90°：转向速度从零平滑升到弯中最大再平滑降回零（不再是一段圆弧），所以入弯出弯没有顿挫；弯道按自身长度计路程，奶狗过弯时速度不变（以前圆弧比对应路程短约两成，每过一个弯画面都会突然慢下来）。因此出弯后的直道比按路程直接算多出 1.91 米，岔路断桥和竖井口的模型都按奶狗实际到达的位置摆放。过弯时奶狗身体向弯内倾斜，镜头微微侧倾，并瞄准前方 3.5 米奶狗实际要走的路（按下转弯前仍朝直行方向），所以镜头和奶狗同时进弯、同时出弯。进入弯前 24 米后按弯道方向转弯，转错或冲出跑道会被抓。在弯道中途才按，会平滑并入弯道。弯前 45 米、弯后 25 米为障碍物预留净空。不转弯时，奶狗过弯 1.5 米后一定判定为冲出弯道（以前只在一个约 1 厘米的瞬间检查，跑得快时常被跳过，奶狗会自己拐过去）。

**转弯提示**：2000 米以内（前中期）屏幕会提示转弯方向和岔路情况，并有提示音；2000 米以后不再提示，要看路面、警示牌和银币自己判断。长落穴、横枝等其他提示不受影响。

**岔路口**：第一个弯之后，约 55% 的普通弯是岔路口（按局内种子和弯的位置决定，不影响障碍生成）。岔路口两边都有路：安全的一边是正常道路，路口有四枚银币引向它；另一边是一小段路，尽头是断桥，路口有“断桥 危险”警示牌和红布条。弯前 55 米先提示“前方岔路 · 避开断桥”，进入 24 米转弯窗口后才显示箭头和断桥在哪一边。走错时奶狗会沿断桥那一边跑出去，靠到桥中间，在过弯后 15.2 米的断口摔下（水渠掉进水里，其他场景掉进桥下深沟），结局为“走上了断桥”。护盾挡不住摔落；金身果实仍会自动走安全的一边。岔路口前后的围墙、树篱、路灯和矿洞岩壁会让开，方便提前看清两边。

**矿洞三岔口**：矿洞里第一个弯之后的弯都是三岔口，只有一条活路。转向另一边是断桥（同上）；不转弯直走，铁轨通向一口积水的竖井，井上有绞架、两盏灯和“竖井 危险”警示牌，奶狗在过弯 9.6 米处掉下去，结局为“掉进了竖井”。提示先显示“前方三岔口 · 两条是陷阱”，进入转弯窗口后显示箭头和“直走是竖井 · 左/右边是断桥”。

## 场景

六个场景合成一条固定路线，每局都从峡谷水渠开始：

| 顺序 | 场景 | 长度 | 特色 |
| --- | --- | --- | --- |
| 1 | 峡谷水渠 | 700 米 | 石桥、栏墙、水面、桥墩；140 米处起跳抓滑索 |
| 2 | 遗迹长廊 | 860 米 | 苔石、树篱、石柱门、树，石坎上长蕨类和小花；125 米处是 290 米长的海上独木桥 |
| 3 | 矿洞轨道 | 1000 米 | 宽阔坑道：岩壁离轨道约 8 米，顶高 12 米，有凸石、钟乳石、水管、电缆、带斜撑的木支架和吊灯、停在支线上的矿石车；140 米处是 210 米的矿车道，七处塌方 |
| 4 | 竹林小径 | 700 米 | 竹篱、成片斜竹（带竹节和竹叶）、石灯笼 |
| 5 | 雪原（每隔一轮出现） | 760 米 | 雪堆、带冰柱的木栏、雪松、带雪顶的路灯、雪人；一直下雪；140 米处从雪岭上的滑索滑进山谷 |
| 6 | 赤岩峡谷 | 700 米 | 红砂岩柱、散落砂岩、仙人掌、挂油灯的木桩；140 米处从台地上的滑索滑过峡谷 |

**下坡滑索**：赤岩峡谷和雪原的滑索长 70 米，起点在约 12 米（峡谷）或 10 米（雪原）高的台地上，终点落在谷底的路面，下方是带河的峡谷。和水渠一样要在崖边起跳抓住，左右摆动收币；没抓住会掉进谷底的河里。抬高的路段下面垫着整块台地（峡谷）、积雪的岩坡（雪原）或土坡（竹林），路边的岩柱、雪松、竹丛都站在上面，不再悬空；路面上的坑和岔路口附近不垫。

第一轮是 水渠 → 遗迹 → 矿洞 → 竹林 → 雪原 → 峡谷，第二轮不经过雪原，然后循环，所以雪原出现的次数是其他场景的一半（第一次约在 3260 米）。每个场景以正常速度要跑半分钟以上。原有三个场景的远景用对应生图的上半部分，新场景的远景由代码绘制。晴/雨/雪每300米按局内种子切换（矿洞内无雨雪，雪原一直下雪，峡谷不下雪）；1000米起进入1500米黑夜、600米白天的循环，夜里路灯点亮。

除矿洞外，每段地图包含连贯的上坡和下坡，后半段还有一座较低的小山；矿洞坑道和海上独木桥是平的。默认奶狗坐矿车时会回头露出惊讶表情，使用高校皮肤时该表情显示在换轨提示旁。[矿车表情素材](art/runner-minecart-surprise-v1.md)

**海上独木桥**：遗迹的独木桥横跨一片海，长 290 米，木头缠着青藤，下面每 9 米有一组交叉木桩，两端是石砌岸边。要走桥中央并跳过三根横枝（第一次撞横枝只引发奶蛙追逐，追逐中再撞会被抓）。桥上有三个弯，弯外侧立着系船柱；中间那个弯一定分岔，其他弯约一半分岔，分岔处另一根木头在过弯 13 米处断掉，水里立着“断桥”牌子，断木上挂红布条。没转弯会冲出独木桥掉进海里；转向不分岔的弯的另一边同样落水；走上断木会在断口落水，结局为“走上了断掉的独木桥”。走在桥上时，海里每隔几秒会有一条鲨鱼从桥边浮起：露出背鳍和水花，水下隐约有黑影，跟着游几秒后沉下去。鲨鱼只是场景，不会攻击。

**道具细节**：约一半的双道倒木上长着蘑菇（红底白点的毒蝇伞、棕色菇和侧面的层孔菌）；遗迹长廊里的倒木和桥上横枝缠着青藤。路灯改成石座、带装饰环的灯杆、弯臂和六角吊灯，雪原的路灯积着雪。

水渠两岸有落羽杉、垂柳和黑松，遗迹沿路有榕树、红枫和银杏。两个户外场景都有果树。矿洞岩壁有枯桦、石化树根、紫水晶、方解石和孔雀石。[树木、矿物与稀有道具素材](art/runner-variety-v1.md)

**场景生灵**：白天水渠上空不时飞过一队白鹭，遗迹和竹林飞过小鸟，雪原飞过乌鸦，都排成松散的人字形、扇几下翅膀再滑翔；海上独木桥一带有海鸥低空盘旋，赤岩峡谷高空有秃鹫打转，路面上偶尔滚过一团风滚草。遗迹的红枫叶、银杏叶和竹林的竹叶不断飘落打转；晴天时遗迹和竹林的路边有彩色蝴蝶扑腾。夜里水渠、遗迹和竹林的路边亮起忽明忽暗的萤火虫，水渠、遗迹和峡谷的夜空有蝙蝠掠过；矿洞里蝙蝠贴着洞顶乱飞，灯光里飘着细小的浮尘。雨天没有蝴蝶和飞鸟。生灵只是场景，不影响玩法。

**脚下扬尘**：奶狗落地扬起一小团尘土，开始下滑时溅起一片，跑动时脚后不断带起一点：雪原是雪粉，赤岩峡谷是红沙，矿洞是灰土，雨天换成水花；二段跳时脚下散开一圈白色光点。镜头随速度略微拉宽视野，落地时轻轻一沉，换道时微微倾斜；减少动态效果时这些都会关闭。

## 道具、金币与追赶

- **磁铁**10秒：奶狗脚下出现旋转红圈，前方14米内三条道的金币飞向奶狗。**护盾**20秒：奶狗被半透明气泡包住，最后3秒闪烁，挡住撞击时气泡炸开并提示。**飞鞋冲刺**5秒：1.5倍速，无视障碍并自动转弯，画面加宽视角、出现速度线和金色光尘。
- **沙漏**5秒：跑动和跳跃速度同时减慢30%，跳跃能覆盖的跑道距离不变。**双倍得分**8秒：距离分和收币分翻倍，银币、金币、钻石仍按实际拾取数量入账。
- **弹簧鞋**10秒：起跳速度提高 38%，单跳最高约 2.3 米（平时约 1.2 米），一跳就能越过滚石和失控矿车，落地前空中停留更久；奶狗脚下出现两只弹簧，落地时压缩、起跳时伸长。它加入常规道具轮换（护盾、磁铁、沙漏、双倍、冲刺、弹簧鞋）。
- **气球**7秒：800 米后道具点有 9% 概率出现（特别模式没有，生成时要求前方约 260 米内没有滑索、独木桥和矿车）。抓住后奶狗挂在一束彩色气球下升到 8 米高（越过遗迹石门和矿洞支架），镜头随之升起变成俯瞰；空中不会撞到任何障碍，弯道和岔路自动走对，不能跳和下滑，但可以左右换道去收前方一条空中金币带（每段保持一条道再斜向另一条道）。最后 1 秒缓缓落地，落地后 1.2 秒内不会被撞；前方出现滑索、独木桥或矿车时会提前降落。
- **神秘宝箱**：300 米后道具点有 12% 概率换成宝箱（650 米后才真正掷骰）。打开得 250 分，奖励由宝箱本身决定（不改变之后的路线）：约 55% 是 40–160 银币，26% 是 3–8 金币，15% 是一个常规道具，4% 是 1 颗钻石，弹出“神秘宝箱 · 奖励”提示。
- 所有道具和拾取物都是 3D 模型，悬浮在同色光环和光柱里并不停转动：红色马蹄磁铁和银色磁极、蓝色圆盾和金十字、带白色翅膀的红跑鞋、木框玻璃沙漏、印着双倍图案的金色奖章、绿色弹簧鞋、缩小的自行车、三只彩色气球、镶金边的木宝箱、带铃铛的红色闹钟、红纸灯笼（夜里发光）。拾取时有粒子和效果提示，右上角道具条显示名称、剩余秒数和进度。银币与金币都有对应颜色的火花和币缘亮光，撞到障碍会扬起尘土。
- 开局只有银币（50 分），1500 米起出现金币（150 分），4000 米起每枚生成的货币有 0.3% 概率为钻石（1000 分）。每连续收 10 枚提高 1 倍，最高 5 倍。4 秒未收币或撞击会重置连击。每跑 1 米得 10 分。
- 1100 米后，可生成的道具点有 6% 概率出现**自行车**，骑行 9 秒，可越过倒木和乱石枯枝。650 米后的户外道具点有 1.5% 概率出现**附魔金苹果**（原“金身果实”）。金苹果是抛光的金色苹果，外面罩着一层闪烁的紫金光，带光晕。掉落前果树会先抖动，掉下和滚入跑道时拖着金紫色火花，同时弹出“附魔金苹果 · 从树上掉下来了”提示。捡到时有大量金紫色粒子、全屏金光闪一下、手机震动和胜利音效，提示显示更久。拾取后有 15 秒无敌、加速、吸币、双倍得分和自动过弯。
- 裂缝和落穴会触发固定机位的下坠演出。奶狗会伸爪、收腿并落入湿岩壁之间的水面。双道火焰由多层高低错落的三维网格组成，火星会从火焰覆盖的整段路面升起。[火焰、水面与下坠素材](art/runner-pit-fire-v2.md)
- 皮肤商城可用跑酷收集的银币、金币、钻石解锁102套 QS 2027 高校主题皮肤。每所学校拥有独立的 4×2 2D 奶狗动作图集，角色的毛色、体态、服装与背部纹样一同设计；奔跑、起跳、二段跳、下滑和摔落都显示该校的角色图集，不再把徽标平面贴到原始奶狗身上。默认奶狗继续免费可选。学校名单包含 [QS 2027 世界大学前100名文章](https://www.topuniversities.com/student-info/choosing-university/worlds-top-100-universities) 中并列第100的 Purdue University 和 University College Dublin，因此共102所。徽标图和独立图集保存在 `public/assets/runner/qs2027/`，徽标来源 URL 逐条记在 `qs2027-top-ranked.json`。余额和选择保存在本机 `nwaxz-runner-skin-shop-v2`；旧衣橱存档迁移余额，已购旧皮肤退还原价货币。
- 商城内 QS 第 1–30 名使用钻石，第 31–56 名使用金币，第 57–100 名使用银币。莫纳什单独定价为 1 枚钻石，同币种内按名次定价，并列同价。
- 开局奶蛙在身后追约 3.5 秒。踉跄后奶蛙重新追近，出现红色边框并响起下水道逃生的笑声。抓捕时奶狗先轻声呜咽，随后被举至奶蛙胸前，奶蛙捧腹大笑。演出约 2.7 秒后结算，可以暂停或跳过。
- **奶蛙的动作与表情**：身后的恐怖奶蛙用两套背面潜行帧交替迈步；踉跄后贴近到身后时张爪扑抓（扑抓帧与潜行帧交替）；快要甩开它时会停下张望。被抓时奶蛙先用潜行帧冲上来，再换成张嘴露牙的扑抓造型，最后抱着奶狗捧腹大笑（大笑造型保留不变）。“夺回金苹果”里跑在前面的奶蛙扔木箱时转身张爪，奶狗撞到东西时转身捧腹大笑；开始界面的恐怖奶蛙每隔约 5.5 秒咧嘴大笑一次。
- **死亡演出**：撞上的一瞬间（演出前 0.22 秒）以四成速度慢放，之后按正常速度进行。掉进裂缝、落穴或水里时，镜头停在原地、抬高并低头跟着奶狗看下去；落水时溅起一柱水花，水面扩散一圈白色涟漪。
- **路边围观**：无限、每日和金币冲刺模式里，每隔 240–500 米路边可能站着一只普通奶蛙（矿洞、暗夜模式、弯道和特殊路段附近不出现）：奶狗还远时挥手、举手，跑过身边时捧腹大笑或欢呼蹦跳，跑过后回头看；刚有惊险闪避时会吃惊；夜里打哈欠、眨眼。只是场景，不会挡路。
- **滑索与气球的摆动**：挂在滑索或气球下时，身体像钟摆一样摆动：左右换道把身体甩向另一侧，再来回摆几下停下；下坡滑索上有速度线，滑轮擦出火星。

## 任务与里程碑

- **任务**同时挂三个，都要在一局之内完成（例如“无限模式跑满 500 米”“惊险闪避 3 次”“完成 1 段滑索、独木桥或矿车”“在‘夺回金苹果’里追上奶蛙”）。完成时屏幕上方出现“✓ 任务完成”横幅，奖励的银币、金币或钻石马上入账；换上的下一个任务从下一局开始算，同一局里不会连环完成。前 24 个任务按顺序逐步介绍玩法，之后九类任务轮流出现，每一轮目标更高。开始界面列出三个任务和奖励，结算界面列出这一局每个任务的进度、完成打勾的任务和换上的新任务。跑满距离的任务只算无限模式，追上奶蛙的任务只算特别模式。
- **里程碑**：无限模式每跑满 1000 米，屏幕上方出现“1000 米 好样的！”这样的横幅；超过自己的最远纪录（纪录至少 300 米时）出现“新的最远纪录！”并闪一下金光。几条横幅同时出现时依次播放。
- 结算界面多一行：惊险闪避次数、这一局最高连击倍率、完成的特殊路段（滑索、独木桥、矿车）数量。

## 续命、道具升级与每日奖励

- **续命**：被抓或摔下去后（无限、每日、暗夜模式），结算界面最上方出现绿色的“续命继续跑 · N 金币”按钮：第一次 20 金币，同一局每续一次价格翻倍。续命后奶狗回到跑道：掉进坑里的放到坑的另一头，没抓住滑索的放到滑索终点之后，走错或冲出的弯算作走对，前方 40 米内的障碍清空，2.5 秒内不会被撞，暗夜模式里奶蛙至少退回 16 米。金币不够时按钮变灰并显示现有金币。特别模式和金币冲刺有时限，不能续命。
- 续命付得起时，被抓或摔下去后先出现“再来一次机会？”：绿色圆环在 4.5 秒内倒数，按“续命”（或回车）付金币回到跑道，按“不用了，看结算”（或 Esc）或等倒数结束进入结算；结算页上的续命按钮仍然保留。付不起时直接进结算。
- **道具升级**：开始界面和结算界面都有“道具升级”。磁铁、护盾、飞鞋冲刺、沙漏、双倍得分、弹簧鞋、自行车、气球各有 5 级，每级持续时间增加基础值的 20%（满级翻倍）；价格依次是 60、150、320 银币，12、30 金币。升级立即用在下一局。
- **每日奖励**：每天第一次打开奶狗快跑时领取，连续天数越多奖励越好：30、50、80 银币，3 金币，120 银币，6 金币，第 7 天 1 颗钻石；断一天或领满一周后从第 1 天重新开始。开始界面顶部显示钱包和当天领到的奖励。
- **生涯数据**：大厅的“生涯数据”按钮打开所有模式累计的局数、总路程、最远一局、最高分、累计银币/金币/钻石、最高连击、惊险闪避、二段跳、打开的宝箱和续命次数。每局结束（被抓、摔落、时间到或获胜）时记一次；续命后再结束只补记新增部分，仍算一局。数据只存在本机浏览器的 `nwaxz-runner-career-v1`，云端同步尚未实现。
- 任务里“一局跑满 N 米”在无限奔跑、每日挑战和暗夜逃亡里都算。

## 纪录、暂停与资源

特别模式键 `nwaxz-runner-chase-record-v1`，无限模式键 `nwaxz-runner-endless-record-v1`，格式不变；每日挑战 `nwaxz-runner-daily-record-v1`（多存一个日期，不是今天的不算）、金币冲刺 `nwaxz-runner-rush-record-v1`、暗夜逃亡 `nwaxz-runner-dark-record-v1`。道具升级存在 `nwaxz-runner-upgrades-v1`，每日奖励的连续天数存在 `nwaxz-runner-login-v1`，数据不合法时从头开始。任务进度存在 `nwaxz-runner-missions-v1`（下一个要发的任务序号、三个当前任务、已完成数量），数据不合法时从头开始。已下线的千米挑战纪录仍留在 `nwaxz-runner-record-v1`，不读取也不删除。手机上跑动时会请求屏幕常亮（浏览器不支持时不影响游戏）；画面上一次滑动可以在途中转向触发第二个动作（例如先跳再左），同一方向滑得再长也只算一次；结束界面和商城列表可以正常滑动，游戏画面不会触发下拉刷新或双击缩放。暂停、切后台、失焦都会冻结全部计时。十二张跑酷PNG保留原尺寸和字节（见 `public/assets/runner/manifest.json`）。
