# 奶蛙逃亡

0.32.0 候选，尚未发布。首页新增第四个独立模式。参考无尽跑酷类型的换道、跳跃、滑铲与转弯交互，使用内置生图功能制作写实峡谷古水渠全景、湿石板和透明障碍图集。实际游戏背景、动态地面及障碍均使用图像资产，代码只负责透视投影和运动，不以纯色几何场景替代绘制素材。完整提示词及原图记录见[写实水渠素材](art/runner-aqueduct-v1.md)。不使用其他游戏的名称、美术、地图或音效。

## 玩法

- 三条轨道自动前进，初速12米/秒，随距离增加，最高28米/秒。
- 左右方向键或 A/D 换道；↑、W、空格跳跃；↓、S 滑铲。手机在跑道上滑动，或使用底部四个按钮。
- 木箱可以绕开或跳过；断桥需要换道或跳过；横梁需要换道或滑铲。泡泡币位于安全轨道，贴地经过收集，每枚加50分；每米加10分。
- 每180米出现一个左右弯道，提前65米显示方向，最后16米内按相应方向转弯。过早输入只换道，错过或转错方向结束本次逃亡。
- 每组机关至少留出两条安全轨道。弯道前后30米及千米目标前后30米不生成机关。
- 首次跑到1000米暂停结算，展示原版奶蛙捧腹大笑；选择“继续 · 无尽逃亡”保留距离与泡泡币并继续加速后的旅程。无尽模式没有终点。
- Esc / P 或右上角按钮暂停；切到后台或窗口失焦自动暂停，返回后手动继续。暂停不推进距离、跳跃或滑铲，长帧最多推进0.1秒。

## 保存与资源

本机独立键 `nwaxz-runner-record-v1` 保存最远距离、单局最多泡泡币和最高分，结算及离开时分别取历史最大值。不读取或迁移浴场、逃生、峡谷存档；没有云端同步、匹配或排行榜。存储不可用时提示纪录仅保留于当前页面。

入口按需导入 `src/runner/game.ts`，纯模拟位于 `src/runner/world.ts`，固定120Hz碰撞步进。进入后加载既有八向行走图集、普通角色图集和三张写实PNG；首页复用写实全景作为入口封面。三张原图共约8.85MiB，保留原尺寸、原字节，不缩小或重编码。载入可返回、失败可重试，迟到请求不得覆盖其他模式。已下载完整离线包时包含跑酷代码和素材，首次在线使用也会由既有PWA缓存；首次未缓存仍需要联网。不扩大启动必需资源清单。

奔跑使用既有恐怖奶蛙背向两帧，结算直接使用普通奶蛙原版图集的捧腹大笑帧。简化动作关闭步态与庆祝晃动，但保留大笑原画。音乐及操作音效遵循全局设置，画布按全局画质限制像素比。不调整生产环境。

## 验证

`server/runner.test.mjs` 覆盖碰撞、跳跃/滑铲、转弯输入窗口、暂停冻结、长帧、收币、损坏纪录、千米目标与无尽继续；40个种子连续模拟至少3000米，核对可通行性和内存边界。该测试纳入 `pnpm check`。

浏览器验收入口为 `ops/runner-browser.mjs`，先运行 `pnpm dev`，再使用独立 Playwright 安装或设置 `PLAYWRIGHT_MODULE`，可选 `CHROMIUM_PATH`。脚本使用独立无窗口浏览器，包含桌面与手机触控、暂停、千米结算、大笑画布、本机保存、无尽继续和失败重开；仅在QA页面创建可控实例，不向生产代码添加调试入口。

浏览器验收与最终命令结果记录在本次 PR。真实手机性能、实际手指触感与扬声器听感需要真机验收；无窗口浏览器结果不代表这些项目已通过。
