# 下水道逃生局域网联机

同一 Wi-Fi 或同一有线网络上的 2–3 人可以加入本地房间。只需一台电脑运行房间服务，其他玩家用电脑或手机的浏览器打开该电脑显示的地址。

## 在主机电脑开房

1. 准备当前版本的源码、Node.js 24 和 pnpm 11.1.3。在项目目录运行 `pnpm install --frozen-lockfile`，然后运行 `pnpm build`。每次更新游戏后重新构建一次。
2. 连接同一 Wi-Fi，运行 `pnpm lan`。如果电脑上有多个候选网卡，程序会列出地址。用 `pnpm lan --host <局域网IPv4>` 指定实际连接的网卡。默认端口是 5189，可用 `--port <端口>` 修改。
3. 所有人打开终端显示的完整网页地址。从「逃生模式 → 多人游戏」创建或加入房间，准备后由房主开始。不需要给手机装程序，也不需要在路由器上做端口转发。

建好后，对局和资源都在局域网内传输。主机程序需在对局期间保持运行，关闭程序后房间和本地游客记录结束。局域网大厅与公网房间各自独立。

如果其他设备打不开地址，确认大家在同一个 Wi-Fi 或同一子网。访客 Wi-Fi 可能隔离了设备，主机防火墙也可能拦截局域网入站连接。
